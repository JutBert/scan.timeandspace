# scan.timeandspace.online

Kostenloser System-Scan von **Time & Space** — gehostet via GitHub Pages.

## Was ist das?

Ein interaktiver Scan mit 12 Fragen, der unbewusste Verhaltensmuster sichtbar macht. Der Scan identifiziert eines von fünf Programmen, die unter dem Alltag laufen — und zeigt, wer davon profitiert.

## Live

[https://scan.timeandspace.online](https://scan.timeandspace.online)

## Struktur

```
index.html          → Scan-Seite (Startseite)
metaschaf-scan.html → Scan (alt, wird weitergeleitet)

```
